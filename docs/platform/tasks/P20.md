## Rules

Token names, roles, labels, `data-*` hooks and string keys stay, so tests and flows hold; any test that asserted a
class name is updated in the same commit as the class. New strings in en and sw with `_meta.reviewP20`
([[COPY-REVIEW]], sw [[SW-REVIEW]]). No new dependency, CDN or vendor. Commits per concern, REQ-UX-01..04.
