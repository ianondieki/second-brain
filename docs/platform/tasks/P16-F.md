## Method

1. **Mechanical items, by script, on the functions M2 touched** (a function counts when an added line falls inside
   it): function length > 50 lines, file length > 800 lines and nesting > 4 levels (Python `ast`; the TypeScript
   compiler API for `.ts`/`.tsx`), `print`/`console.log`, TODO/FIXME/XXX, emoji, `dangerouslySetInnerHTML`.
2. **Items that need reading**, split between two reviewers, grep-first then the routers, services, jobs, API client,
   proxy and auth, billing and tracker components read in full; every finding verified by a probe or a test.
   CRITICAL: credentials, SQL injection, XSS, input validation, insecure dependencies, path traversal, open
   redirects, server-only values in client bundles. HIGH: missing error handling. MEDIUM: accessibility axe cannot
   see, mutation, missing tests.

- **A flaky e2e found by this branch's CI** (run 36794026674, green after one retry): `research.spec.ts:102` (mobile)
  got a plain-text 500 from `GET /api/admin/research/sources`. That body is Next's rewrite proxy failing to reach the
  API (the API's own 500 is JSON since P16-E1). Next proxies `/api` through httpxy's own keep-alive agent, which has
  no idle timeout, so the API closes idle sockets (uvicorn's default after 5 s); the e2e suite's ordinary gaps between
  requests sometimes reused a socket at the moment it closed. `06a54fe` keeps idle connections 75 s, with a test;
  `85f6f5f` corrects the first commit's claim that the proxy then always closes first (round 3). **Left:** the race is
  narrowed, not removed: a socket idle exactly 75 s and reused at the moment the API closes it would still fail. A
  client-side idle timeout or a retry of idempotent requests would remove it (not configurable through Next's
  rewrites); and when the Phase 8 edge proxy (Caddy, ADR-007) talks to the API, its upstream idle timeout must be
  shorter than the API's (Caddy's default is believed to be 2 min, not checked).
- **The flake check on `866aec2` stands:** its three runs had Playwright 162/162 with no retry in each, the demo story
  1/1 and the backend 4147.
