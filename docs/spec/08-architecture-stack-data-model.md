## 8. Architecture, stack & data model

Decisions are final unless an ADR supersedes them.

| Concern | Decision |
|---|---|
| Backend | Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.0 async (psycopg 3), Alembic, `uv`; package `backend/src/bridge/` |
| Agents | LangGraph ≥1.2 with `langgraph-checkpoint-postgres` |
| Database | PostgreSQL 16 + pgvector (HNSW), `citext`, `pgcrypto`; one datastore for data, vectors, queue, sessions |
| Jobs | Procrastinate (Postgres-backed, periodic tasks, `queueing_lock`); no Redis in v1 |
| Frontend | Next.js (current stable major, pinned in ADR-001) App Router + TypeScript + Tailwind + shadcn/ui, standalone output; `/api/*` rewritten to FastAPI (same origin); typed client via `openapi-typescript`, drift checked in CI |
| Auth | Backend-owned: argon2id (m=64 MiB, t=3), magic links, GitHub OAuth (also links repos), Google OAuth; server-side sessions in Postgres, `httpOnly; Secure; SameSite=Lax` cookie + CSRF double-submit; TOTP mandatory for org owner/admin/signatory/reviewer, D2 developers and staff; TOTP/passkey step-up for signing, endorsements, payment confirmations and access-policy changes |
| Tenancy | `organizations` + `memberships`; **Row-Level Security** on every org-scoped table via `SET LOCAL app.user_id/app.org_id` per transaction (jobs too, one tenant each), plus `require_role` dependencies; cross-org aggregates (trends, responsiveness, research hot pairs) read only the non-org-scoped `signal_events(item_id, kind, actor_hash, org_hash, ts)` table (ids, enums and salted hashes, written in the same transaction as the source event) under a dedicated `aggregate_worker` role; no app or worker role has BYPASSRLS or table ownership (migrations use a separate owner role); RLS filters rows, so Tier-2 columns sit in `proposal_confidential` behind `tier2_reader` (`docs/spec/06-feature-modules.md#61-central-repository--tiered-disclosure`). Errors: non-member/non-party → 404; member or party lacking role or precondition → 403 |
| Storage | S3 af-south-1: `uploads` (presigned, ClamAV in its own memory-limited container), `evidence` (Object Lock governance mode, retention per object from the `docs/spec/10-security-privacy-compliance.md` schedule; packs pseudonymised with a separately held key map), `backups` |
| Email / WhatsApp / Voice | Postmark (SES alternative) behind `EmailProvider`, SPF/DKIM/DMARC `p=quarantine`, bounce webhooks; WhatsApp Cloud API utility templates (Release 2); TTS/STT for the adviser (Release 2: Azure AI Speech `sw-KE-ZuriNeural`/`en-KE-AsiliaNeural`, Groq Whisper paid tier — edge-tts is not allowed in production) |
| Payments / tax / identity | `PaymentProvider` (Daraja STK, Paystack), `InvoiceIssuer` (sequential numbers, eTIMS), `SmsProvider`, `KycProvider` (`docs/spec/06-feature-modules.md#64-authorship-provenance--watermarking-the-honest-watermark` item 8), each with a Fake used in CI and staging |
| Embeddings | Self-hosted `BAAI/bge-m3` (1024-dim, multilingual incl. Swahili) via sentence-transformers in fp16/int8 on the worker; `VoyageAdapter` optional (DPA flag); fixed-vector fake in CI; `embed_model`/`embed_version` stored per row; model change triggers re-embed job. **Anthropic has no embeddings endpoint.** |
| Provenance | As `docs/spec/06-feature-modules.md#64-authorship-provenance--watermarking-the-honest-watermark` |
| Hosting | AWS af-south-1 behind Cloudflare (Nairobi PoP, WAF); everything containerised, plain Postgres + S3 API so it can move to a Kenyan data centre for government clients |

**LLM layer (`bridge/llm`):** `LLMClient.complete(task, messages, schema, tools=None, effort=None, cache_breakpoints=None) -> Result{parsed, stop_reason, usage, citations}` and `batch_submit/poll`. Single adapter `AnthropicAdapter` (official SDK: Batches, caching, citations, server tools); no Groq in the backend (ADR-005). `ai/models.yaml` maps task → model/effort/max_tokens/batchable/confidential (default `confidential: true`). **No model ID is hard-coded elsewhere.** Structured output: native JSON-schema or `tool_choice: auto` with `strict: true` — **never forced `tool_choice`** (400 on Opus 5.5 and Fable 5.1). `stop_reason == "refusal"` → log, human queue, at most one retry on the next allowed model; `max_tokens` → retry once at 2×; schema failure → retry once with the error, then dead-letter queue. `ModelPool` cooldowns and `TokenPacer` carried over. Every call writes `llm_calls(tenant, task, model, tokens incl. cached, cost_usd, latency, status, trace_id)`; pre-call budget check enforces per-tenant monthly caps from `plans.limits`, a global daily cap and `LLM_KILL_SWITCH=1`. Untrusted text goes inside `<submission nonce=…>` blocks after sanitising (strip HTML/markdown links, zero-width and bidi controls, base64 runs >200 chars; length caps).

**Migrations:** Alembic only, one per PR, expand/contract for destructive changes, `alembic check` in CI; RLS policies, append-only triggers and grants live in migrations. `python -m bridge.seed` is idempotent (niches, plans, NDA v1, holidays, directory) and outside `APP_ENV in (test, staging)` refuses to set any org above `unclaimed`.

**Periodic jobs** (Africa/Nairobi; idempotent; healthchecks.io ping): `reminders.dispatch` */15 min; `reminders.org_digest` 08:30; `scouts.scan` per agent cron (default 06:00), `on_new` agents on `proposal.published`; `research.refresh` weekly per niche×region (Batch); `trends.recompute` 02:00; `recommendations.recompute` 03:00; `engagements.sla_check` hourly; `billing.renewal_reminders` 09:00; `billing.mpesa_reconcile` */10 min; `provenance.anchor_chain_heads` hourly; `audit.verify_chain` nightly. Release 2 adds `provenance.ots_upgrade`, `similarity.monitor`, `github.backfill`.

**Repo layout:** `backend/` (`src/bridge/{main,config,db,audit,auth,tenancy,directory,profiles,proposals,provenance,problems,matching,engagements,reminders,notifications,billing,integrations/github,llm,adviser,jobs,admin}`, `tests/{unit,integration,contract,evals}`), `frontend/` (`app/(public|dev|org|admin)`, `components/`, `lib/api/`, `e2e/`), `infra/` (`docker-compose.dev.yml`, `docker-compose.prod.yml`, `Caddyfile`, `terraform/`), `reminder/ adviser/ tests/` (unchanged), `legacy/`, `CLAUDE.md` (spec index), `docs/spec/` (the spec), `docs/platform/{PLAN,REQUIREMENTS,PROGRESS,DECISIONS-NEEDED,GATES,THREAT_MODEL}.md`, `docs/platform/adr/`, `docs/platform/tasks/<REQ-ID>.md` (task cards), `docs/legal/`, `docs/runbooks/`, `.github/workflows/`, `.claude/agents/`.

**Non-functional:** API p95 ≤300 ms reads / ≤800 ms writes excluding LLM; anything calling an LLM is async (job + in-app/SSE status). 99.5% monthly availability target; RPO 15 min (RDS PITR 14 days); RTO 4 h; nightly `pg_dump` encrypted with `age` to an Object-Locked bucket in eu-west-1 in a separate account; quarterly restore drill logged. OWASP ASVS L2; rate limits (login 5/min/IP+account, API 60/min/user, public search 30/min/IP); CSP nonces, HSTS preload, `X-Frame-Options: DENY`; secrets in SSM Parameter Store, rotated every 90 days; `gitleaks`, `pip-audit`, `npm audit`, `osv-scanner`, Trivy, CodeQL in CI. Infra cost ≤USD 150/month at pilot scale excluding LLM. Observability: structlog JSON (no PII), OpenTelemetry to Grafana Cloud free tier, Sentry with PII scrubbing, LLM traces in the `llm_calls` table + OTel (Langfuse Cloud with `redact()` optional as a DPA'd sub-processor; never self-hosted in v1 — it needs ClickHouse and Redis), Better Stack uptime on `/healthz` and `/readyz`.

**Testing & CI:** pytest (plus the legacy unittest suite); testcontainers `pgvector/pgvector:pg16` with `alembic upgrade head`; parametrised RLS tests generated from table metadata; Hypothesis stateful tests for state machine and hash chains; `respx` fakes for Daraja, Paystack, Postmark, GitHub, Meta (in the style of `tests/adviser_fakes.py`); `FakeListChatModel`/recorded cassettes, fake embedder, local TSA (`openssl ts`, test CA), ClamAV test-signature image, egress allowlist for container registries only — **`pr.yml`, `main.yml` and `make check` never call a real LLM or network**; the `nightly.yml` evals job is the only allowed egress (separate Anthropic key in GitHub secrets, ≤USD 5 enforced via the `llm_calls` ledger, synthetic or G-EVAL-approved gold data only, allowlist `api.anthropic.com` for that job); Schemathesis contract tests; Playwright (Chromium desktop + Pixel 5 360 px, axe on every page) covering the `docs/spec/14-definition-of-done.md` scenarios; Vitest; coverage ≥85% overall, ≥95% on `engagements/`, `billing/`, `provenance/`, `auth/`, `tenancy/`. Workflows: `pr.yml` (ruff/mypy `--strict` on `backend/`, eslint/tsc on `frontend/`; unit, integration, migration up/down/up + `alembic check`, OpenAPI drift, Playwright against the compose stack with Mailpit/MinIO/ClamAV, scanners, legacy tests via `scripts/run_legacy_tests.py` on ubuntu + windows), `main.yml` (multi-arch images → GHCR → staging → smoke → production behind a manual-approval Environment; AWS via GitHub OIDC; migrations as a one-off task before rollout), `nightly.yml` (LLM evals ≤USD 5, weekly restore test, Renovate). Staging is a test environment: `APP_ENV=staging` enables the test clock, fake KYC/SMS and fixture orgs ("Telco A (fixture)", never real brands shown as verified); the test-clock router is excluded from the production image at build time (CI asserts 404). Deploy: 1× `t4g.large` Docker Compose (Caddy, web, api, worker, clamav), RDS `db.t4g.small` Postgres 16 with PITR, S3, Cloudflare (ADR-007); Terraform in `infra/terraform/`; `make dev` brings up the seeded local stack.
