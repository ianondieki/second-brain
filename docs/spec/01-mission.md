## 1. Mission & product summary

A hosted, multi-tenant web platform in the same repo (new `backend/`, `frontend/`, `infra/`), with the existing single-user tool (`docs/spec/02-existing-repo.md`) kept unchanged as a local companion:

- **Developer side:** publish problem–solution proposals to a **central repository** with a **timestamped authorship record**, tag several target organisations, see **trending problems and projects** per niche/county, get **personalised "what to pursue" recommendations** from the **research agent's** cited problem cards plus their own history, track every deal on a **KUCCPS-style tracker**, and receive **daily reminders** tied to real milestones.
- **Enterprise side** (companies, SACCOs/MFIs, schools, universities/TVETs, governments, NGOs/PBOs, others): a verified profile in a **directory by niche**, a form-configured **scout agent** that scans the repository and emails the PM team a digest, an inbox to review/decline/express interest, the same tracker, and **progress reminders** stating whether things go as agreed.
- **Platform admin console:** claims, moderation, research approval, disputes, billing ops, audit log.

**Launch scope:** Kenya only (47 counties), two wedge niches actively seeded (Microfinance & SACCOs; Higher Education), all other niches browsable; 10–20 concierge-onboarded anchor orgs (`docs/spec/05-subscriptions-billing.md` coupon). East Africa in Release 3 (`docs/spec/11-delivery-phases.md`).
