## 4. Non-negotiable principles

1. **Plain code decides; the LLM only words, scores within bounds, or explains.** State transitions, sends, deadlines, health, gating, ranking thresholds are deterministic and tested. This is the existing repo's principle; it now governs everything.
2. **Honest IP claims.** Never "theft-proof", "cannot be stolen", "protected idea", "patented". In the i18n namespaces `engagement.*`, `tracker.*` and `email.em2.*`, "Approve"/"approved" appears only in a message that also carries a non-binding qualifier ("non-binding" / "not a contract or a commitment to buy"); other namespaces (moderation holds, admin-approved invitations, EM8 verification results) are exempt. The CI copy-lint (`copy/banned_claims.txt`, co-occurrence rule for this pair; EM2 and the stage-3 label are positive fixtures, a moderation-hold string the exempt fixture) fails the build on violations. Approved phrasing: "timestamped evidence of what you submitted and when", "shown to verified people at organisations that accepted our NDA, plus platform staff under logged, owner-notified break-glass", "every view is logged and watermarked to the viewer".
3. **Human in the loop for every commitment.** Agents propose; a named human accepts, declines, signs. No agent has side-effecting tools.
4. **No spam, no false affiliation.** Unclaimed orgs are never emailed proposal content; no third-party logos; invitations only as `docs/spec/06-feature-modules.md#62-company-directory-by-niche-claimed-and-unclaimed` allows.
5. **Privacy by design (Kenya DPA 2019).** Minimisation, consent records, export/delete, no personal data about private individuals in research, no training on idea content.
6. **Simple UI.** ≤5 primary nav items per side, one primary action per screen, mobile-first at 360 px, WCAG 2.2 AA, English first / Swahili-ready.
7. **Radical transparency, one truth.** Both parties see the same tracker generated from the same append-only, hash-chained event log. Internal notes exist but can never change state.
8. **No custody of funds** in v1 (National Payment System Act 2011). Subscriptions only, via licensed PSPs; project money moves off-platform and is recorded with dual endorsement.
